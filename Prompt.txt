# 12. COLOUR RULE

The colour system should follow roughly:

**60% light / paper**
**25% dark**
**10% pink**
**5% other accents**

The accents should create hierarchy, not noise.

Do not use every accent colour in every section.

A section should normally have:

* one dominant background
* one primary text colour
* one accent
* optional secondary accent

Colour should communicate meaning.

For example:

Pink = personality / brand

Yellow = action / CTA

Dark = authority / strategy

Paper = editorial / reading
